## 目的と読者

香港の工事現場・屋宇裝備（BSE）で聞く jargon を、スマホですぐ引ける公開辞書。例: 「幫辦」は通常 Inspector of Works（工程督察）を指すスラング。

読者の第一は Justin と、同じ現場の香港の人。公開 Pages なので、外から来た人でも意味が分かること。画面の言葉は **繁体字中国語**。官銜・正式英語は **English のまま**出す（例: Inspector of Works、Authorized Person）。日本語 UI にはしない。

### ロック済みで、UI が守ること

- **1 行 = 1 語義。** 同じ見出しに複数義があるときは、必ず全部見せて区別する（つぶさない）。
- **幫辦** はスラング。官銜と 1:1 に畳まない。
  - Inspector of Works ＝ 工程督察
  - Works Supervisor ＝ 監工（一級／二級）
  - Clerk of Works ＝ 工程監督
  - 皇家佬 は政府現場担当のスラングで、官銜ではない
- **地盤三寶** は 3 義、全部出す: (1) 證件: 身份證、平安卡、工人註冊證 (2) PPE: 安全帽、安全鞋、反光衣 (3) PPE: 安全帽、安全帶、安全鞋（medium）
- **大力佬** は 2 義: (1) 登録職種 索具工（叻㗎）／金屬模板裝嵌工 (2) 口語の大力雜工（官銜なし。雜工／CID と 1:1 にしない）
- **略語は語義ごとに分ける:** FS / FD / BA / SP / BS / BM。凡例や「図面の略語は文脈を見ること」が分かるようにする。
- **Jyutping** は CSV にあるが、コンパイラ追加。教材の読みとして大きく権威づけしない。出すなら控えめ（小さく、または詳細に）。
- **Hard-ban:** 病院名、QEH、Block T、手術室、プロジェクト ID、人名を、画面にもサンプルにも出さない。

### 敏感語（公開ページの default、ロック済み）

| 語 | 扱い |
|---|---|
| 咖喱 | **公開に出さない。** CSV にもない。`held-back-sensitive.md` のみ。検索しても出ないこと。 |
| 飛土 | CSV にある。**初期状態では隠す。** 出すときは警告（重大事故のスラング）を先に。デフォルトONの一覧・検索に出さない。 |
| 爛仔會 | 見出しにも alias 索引にも出さない。判頭會の注記の貶義別名としてだけ。 |
| 企鵝、消防員、飛機師、白紙、蛇王 | 残す。貶す採用・振る舞いのスラングだと **明示**する。消防員・飛機師は一般の職業名と取り違えない。 |

`register` や note にある pejorative / filter の合図を、見た目で分からせること。

## 画面（v1）

モバイル優先。電話が本拠（幅 320–430px、**縦横比の違いでも使える**）。デスクトップでも壊れない。

必須の画面:

1. **一覧 / ホーム** — すぐ検索できる。カテゴリで絞れる。必要なら見出しの字・アルファベットでも辿れる。空の状態と、ヒットなしもデザインする。
2. **検索結果** — 見出し語・別名（`term` / `alt_terms` / `formal_zh` / `english` / `spoken_form`）にヒット。複数義は同じ見出しの下に「義 1・義 2」と分かる。
3. **語の詳細** — 見出し、英語、正式中文（あれば）、短い定義、注記、カテゴリ、register（俚語 / 官式 / 正式 / 両方）、他の語義への導線。出典 ID を大きく見せる必要はない（詳細のすみでよい）。

任意（v1 で短くてよい）: この辞書についての短い説明（何の辞書か、スラングと官銜は別物、略語は文脈次第）。長い About は不要。

v1 に入れない: アカウント、編集画面、音声再生（Jyutping の読み上げ）、独自ドメイン、印刷専用レイアウト、PDF。

## ビジュアルの方向（像素は Celine に任せる）

現場の手帳・小さな語彙帳のように、**すぐ読めて信頼できる**こと。可愛い教材風（mallow-cal の幼稚園・ピンク、koko-hangul の学習カード）にはしない。暗く重い「工事現場」テーマにも寄せすぎない。静かな実務ツール。

- 見出し語が一番目立つ。定義は短く読める。
- スラングと官銜、複数義、貶義・警告が、色やラベルで一目で分かること（コントラストは充足）。
- 無料のフォント・素材のみ。既存の justinksw Pages の見た目をコピーしなくてよい（別ハブ）。
